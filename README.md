# I-Re-horizon

Research workspace for K2-Horizon-MoVA-36B-A4B analysis, tokenizer research,
architecture analysis, and model surgery experiments.

## Structure

- `analysis/` — analysis results
- `scripts/` — research and utility scripts
- `tokenizer/` — tokenizer experiments
- `config/` — model configuration snapshots
- `data/` — small metadata only
- `checkpoints/` — experiment checkpoints and notes

Large model weights remain on Hugging Face and are not stored in this repository.
